MVP focus

Goal: individual-first AI operating system

One human, one agent, one text workspace that becomes useful.

The next phase should prove the core dohc loop: text as the shared substrate, agents as capable operators, and trustworthy structure around real work.

North Star

Start from nothing. Talk to dohc. End with a working personal system you can inspect, edit, and trust.

Team and company workflows should grow from this, not replace it.

Priority Stack

01

Stabilize the v2 foundation

Finish production-equivalent QA for Y.Doc canonical editing, Hocuspocus sync, markdown projection, anchored suggestions, and semantic agent edits.

02

Make solo dohc magical

A single person should get clear value for personal life, work, projects, research, planning, finances, writing, or learning.

03

Make text ownership real

Strengthen import, export, recovery, and source visibility so the user feels their work is portable, inspectable, and theirs.

04

Sharpen the agent work loop

The agent should reliably read context, create atoms, propose edits, cite sources, explain changes, and choose workspace context reliably.

05

Turn repeated work into skills

When a user likes a result, dohc should help preserve the process as a reusable skill, workflow, or playbook.

06

Make source-backed apps native

Dashboards, tables, and graph views should make text feel like software without hiding the source.

07

Keep trust boundaries sacred

Preserve permissions, provenance, locks, review gates, sandboxed HTML and no silent cross-workspace leakage.

08

Expand to teams after solo works

Shared workspaces, org memory, and team workflows should extend a great personal system, not compensate for a weak one.

Execution Order

1 Dogfood the coreEditor, sync, projection, suggestions, and agent edits.
2 Prove the empty-workspace momentFrom blank state to useful personal system.
3 Compound the workMaps, skills, source-backed apps, and repeatable workflows.
4 Scale the boundaryTeams and orgs after the individual loop is undeniable.

Operating Principles

Text is the primitive The source should remain readable to humans and workable for agents.
Agents wrap tools Deterministic systems provide storage, sync, auth, diffs, and review gates.
Record useful artifacts Documents, chats, decisions, meeting notes, and agent actions should improve future work.
Obvious beats clever If a human cannot inspect it or an agent cannot maintain it, simplify the shape.
