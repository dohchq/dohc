# A harm line names a case that may fail a harm check (text lost, a file that
# never settles, a refused read), with its reason in the pull request that
# listed it. Any other harm fails the judge.
#
# A count line is `<run> <check> <count>`, for the gate's sample (`sample`)
# and the ignored full run (`full`). These checks find a document that
# changes once on the first save and loses nothing. They are counted, not
# blockers. A run must meet each count exactly: a higher count is a
# regression, and a lower one means lowering the line here.
